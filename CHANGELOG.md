# Changelog

All notable changes to AL Buddy are documented here. This file is for users:
it is written in their words and about what they see. Build, CI, dependency and
refactoring work stays out of it.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and
the project aims to follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
